# harmonica-eval — 口琴音频检测分析研究

面向口琴练习场景的演奏特征提取与对比分析研究项目。

**阶段：立项 / 待定技术路线。**

项目仓库与上下文已就绪，**尚未写入任何算法实现**——技术路线由项目负责人确定后再落地。

## 目录结构

```
harmonica-eval/
├── docs/            研究文档（上下文、章程、后续设计文档）
├── src/             分析代码（待技术路线确定后填充）
├── scripts/         实验与数据处理脚本
├── tests/           测试
└── data/
    ├── reference/   标准/参考演奏音频
    ├── user/        待评价的用户演奏音频

```

## 环境

见 `docs/01-charter.md` 的"环境基线"。核心依赖已在本机安装：librosa 0.11.0、numpy 2.4.4、scipy 1.17.1、soundfile 0.13.1、torch 2.11.0、torchaudio 2.11.0、matplotlib 3.10.9、pandas 2.3.3、pytest 9.1.0，系统 ffmpeg/ffprobe 可用。
