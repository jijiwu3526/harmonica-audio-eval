  288: ### 4.4 `run(surface) -> AlgorithmResultEnvelope`
  289: 
  290: **职责**：算法入口。流程：读端口 → 比较 → 汇总 → 装信封。
  291: 
  292: - **输入**：`surface: AlgorithmDataContract`（**只读**，只有 `read()` 与 `manifest()`）
  293: - **输出**：`AlgorithmResultEnvelope`（字段见 `contract.py`）：
  294:   ```
  295:   algorithm_id       = ALGORITHM_ID        ("pitch")
  296:   algorithm_version  = ALGORITHM_VERSION   ("1.0.0")
  297:   status             = "OK" | "FAILED" | "INCOMPATIBLE"
  298:   # ★ 更正（P1 审查 F10）：原写 "SUCCEEDED" —— 契约的冻结取值域是
  299:   #   {'OK','FAILED','INCOMPATIBLE'}（contract.py 的 AlgorithmResultEnvelope）。
  300:   #   写 "SUCCEEDED" 会被 C1 的 schema 校验判为非法。
  301:   required_ports     = ("pitch.reference", "pitch.practice", "notes.reference", "notes.practice")
  302:   consumed_ports     = 实际成功读取的端口元组
  303:   payload            = §4.3 的 5 键字典（失败时为 {}）
  304:   error_code         = ErrorCode 的值 或 None
  305:   error_detail       = 人类可读说明 或 None

  309: - **算法口径**（顺序写死）：
  310:   1. `t0 = time.perf_counter()`
  311:   2. `man = surface.manifest()` —— 校验四个必需端口都在（缺任一 → 失败信封）
  312:   3. `ref_pitch = surface.read("pitch.reference")`，其余三个同理
  313:   4. `res = compare_pitch_curves(ref_pitch, prac_pitch, ref_notes, prac_notes, sample_rate)`
  314:   5. `payload = summarize_deviations(res["per_note_cents"])`
  315:   6. `payload["sample_rate"] = <两侧的采样率>` —— **补上第 5 个键**
  316:   7. 装信封返回，`elapsed_sec = time.perf_counter() - t0`
  317: 
  318: - **★ 失败语义（本函数最容易写错的地方）**：
  319:   **任何失败都必须返回 `status="FAILED"` 的信封，绝不抛异常。**

  321:   用 `try/except Exception` 包住 2–6 步，在 except 里装失败信封：
  322:   - `error_code = ErrorCode.ALGORITHM_FAILED.value`
  323:   - `error_detail = f"{type(e).__name__}: {e}"`
  324:   - `payload = {}`
  325:   - ★ **不留 `error_code=None`**：失败却无码，C1 无法分类。
