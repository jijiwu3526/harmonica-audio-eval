---

## ROLE

**Web Cockpit** —— 人类操作与观察界面。**开发者调试视图**。

## WORKFLOW POSITION

最外层旁路。**可缺席**：删除它，C1/C2/C3 仍须无头跑通（Invariant F）。
对应宪章 §44.12 Human Control Cockpit 的最小实现。

## CAPABILITY

- 文件选择与运行控制
- 波形 / 曲线 / 结果叠加展示
- 算法参数调试

## BOUNDARY（明确不做）

- 不进入音频计算热路径
- **不保存 Core 状态**
- 不执行 DSP；**不直接读数据面**；不解释算法内部
- **不是面向终端用户的产品界面**（见下方边界裁定）

## 边界裁定（负责人已定，v2.1）

`SPEC.md` §1 禁止「产品化/UI」。本组件与该条的关系已澄清：

| | 产品化 UI（禁止） | 本组件 C4（允许） |
| --- | --- | --- |
| 服务对象 | 终端用户（口琴学习者） | **开发者** |
| 运行环境 | 手机端成品 | **Mac 端** |
| 阶段 | 远期产品 | v0.1 调试期 |
| 依据 | SPEC §1 | 负责人裁定 + 宪章 §44.12 |

**平台路线**：Mac 端先行 → 核心调试完毕 → 再移植手机端。

## CRITICAL DECISIONS

| # | 决定 | 理由 |
| --- | --- | --- |
| D1 | **只与 C1 通讯** | 不直连 C2/C3，避免 UI 进入计算热路径 |
| D2 | **只读投影** | C1 提供下采样投影，C4 不持有音频或数据面缓冲 |
| D3 | **无持久状态** | 纯视图；崩溃/断开不影响会话 |
| D4 | **不解释算法内部** | C4 只展示 C1 给的投影，不解析 payload 语义 |

## BUDGETS

| 项 | 预算 | 依据 |
| --- | --- | --- |
| 内存 | 不持有音频缓冲 | D2 |
| 投影数据量 | 受 C1 下采样投影约束 | 避免"人类面对几千个文件"（宪章 §44.12） |
| 崩溃影响 | **零** | Invariant F |

## RISKS

| # | 风险 | 后果 |
| --- | --- | --- |
| R1 | C4 直连 C2/C3 取数据 | 深组件被绕过；UI 崩溃可影响数据面 |
| R2 | C4 承担验收职责 | 违反 §36：验证是角色，不是产品件 |
| R3 | 边界措辞含糊 | 执行者可能把「禁止产品化 UI」误读为「禁止一切界面」→ **已由上方裁定消除** |

## FEASIBILITY

**可独立承包且无外部阻塞。** 边界清晰、禁区明确、可缺席、无前置未决项。
是理想的**首个实现目标**：能最快让负责人看到可操作的东西。
