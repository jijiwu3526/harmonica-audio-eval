### ★★ 关键风险：全等长正在掩盖一个真实缺陷

### ★★★ 最重要的发现：`中位绝对音分` 单独用会漏掉错音

```
03_气息不匀   中位 0.00  最大   0.00   ← 音高确实没变，0 是正确的
04_错音       中位 0.00  最大 201.75   ← ★ 有一个音错了 286 音分，中位数却是 0
```

**「错音」是单点离群，而中位数对离群点不敏感。**
★ 若验收只看 `median_abs_cents`，**04_错音 会被判为「音准完美」**。

★ **这与 `FILE-202` 已有的设计形成对照**——那边专门有
`per_note_cents` 逐音序列 + `max` 类统计，正是为了暴露离群点。
★ **建议未来的 `pitch` 指标除中位数外，必须同时给出逐音序列或最大值。**

### ★ 02/05 配对失败的根因（★ 重要）
