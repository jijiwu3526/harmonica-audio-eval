### 2.3 ★ 三个真障碍（★ 实测，★ 推翻了此前部分结论）

```
① ★ 没有 pyproject.toml / setup.py
   → 别人只能从源码目录 import，★ 不能 pip install
   → 而手机端打包（Kivy / Briefcase / Chaquopy）要求它是【一个包】
   → ★ 【这条是硬障碍，★ 不解决则「上手机」无从下手】

② ★ import contract 顶层就拖进整个 numpy（100+ 子模块）
   → 「契约层零依赖」是此前评估的【只读代码】结论，★ 实测【不成立】
   → ★ 手机端若不想背 numpy，★ 那连契约都 import 不了

③ ★ import host 拖进 librosa + numpy + scipy
   → librosa 依赖 numba / LLVM，★ 是手机端最难搞的一个
   → ★ 实测确认：★ librosa 只在 core/features.py 两处调用，★ 可手写替换
```
